# 词迹 WordTrace

> **Read it. Meet it. Remember it.**  
> 基于个人语境阅读的离线英文词典与艾宾浩斯间隔记忆 Web App (PWA)。

---

## ✨ 核心特色

1. **默认不带任何预设单词，所有词汇皆来自阅读**：
   - 粘贴文章、随笔、新闻或导入本地文本。
   - 极简阅读器排版，支持「雅白」、「护眼羊皮纸 (Warm Sepia)」、「深色暗夜」三种沉浸模式。
2. **划词即查，语境留存**：
   - 选词划线自动弹出牛津/权威英汉释义气泡与美音朗读。
   - **智能词形还原**：选 `discovered` 自动定位词根 `discover`。
   - **自动捕获原句**：将你读到的那一整句上下文与文章标题永久存入词卡。
3. **经典艾宾浩斯 SM-2 记忆曲线复习**：
   - 3D 翻转卡片：正面呈现单词与当初的真实上下文句子，背面呈现释义与打分。
   - 自动调度下次复习间隔（重来/困难/良好/简单）。
4. **微信无阻碍分享与全量备份 (.txt)**：
   - **单书共读分享**：导出指定一本书与全部生词，自动抹除个人记忆进度供朋友共读。
   - **微信秒传**：采用微信 100% 畅通的 `.txt` 格式，支持文件导入或直接从微信聊天复制长文本粘贴导入。
5. **100% 免费 & 隐私离线**：
   - 纯客户端浏览器 IndexedDB 存储，绝不上传私密文章。
   - 支持 PWA，可直接“添加到手机桌面”，断网也能随身背单词。

## 🚀 如何发布到 GitHub Pages（30 秒搞定）

本项目为**纯前端零依赖工程**，无需在电脑上安装 Node.js 或编译：

1. 在 GitHub 上新建一个公开或私有仓库（例如 `WordTrace`）。
2. 将本文件夹里的所有文件（`index.html`、`app.js`、`db.js`、`dict.js`、`srs.js`、`style.css`、`manifest.json`、`sw.js`、`icon/`）上传或推送到该仓库的 `main` 分支。
3. 进入 GitHub 仓库设置：**Settings** -> **Pages**。
4. 在 **Build and deployment** 下方的 **Branch** 选择 `main` 分支，文件夹选择 `/ (root)`，点击 **Save**。
5. 稍等半分钟，GitHub 会生成你的专属在线访问链接（如 `https://yourname.github.io/WordTrace/`）。

## 📱 如何安装为手机 App (PWA)

- **iPhone (iOS Safari)**：打开你的 GitHub Pages 网址，点击底部「分享」按钮 -> 选择「添加到主屏幕」。
- **Android (Chrome / Edge)**：打开网址，点击右上角菜单 -> 选择「安装应用」或「添加到主屏幕」。
- **电脑 (Chrome / Edge)**：地址栏右侧会出现一个「安装」小图标，点击即可化身独立桌面应用运行。
