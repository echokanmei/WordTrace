# 词迹 WordTrace - 扩展词库目录 (Extended Dictionaries)

本目录用于存放高阶专业或扩展词库（例如托福、雅思、GRE、医学、计算机等专有词库）。

## 词库格式规范 (JSON)

你可以随时在此目录下新增 `.json` 扩展词库，结构非常简洁规范：

```json
{
  "name": "托福高分核心扩展词库",
  "version": "1.0",
  "words": {
    "aberration": ["/ˌæb.əˈreɪ.ʃən/", "n. 越轨；离开正道；异常行为 [托福核心]"],
    "benevolent": ["/bəˈnev.əl.ənt/", "adj. 仁慈的，乐善好施的 [托福核心]"]
  }
}
```

当用户阅读高难度专业文章遇到未收录生词时，前端会引导用户一键载入该目录下的扩展包，保持主程序轻盈秒开的同时，支持无限专业扩展！
